# Checkpoint 16 — Mobile Robot Kinematics

ROSBot XL麦克纳姆轮运动学学习项目，目标环境为Ubuntu 22.04 / ROS 2 Humble。

## 当前状态

- 独立仿真工作空间已完成最小构建、控制器激活、六向命令/里程计与停止检查，以及Gazebo模型显示验证。
- 本仓库目前仅包含项目说明和忽略规则，尚未实现下列作业包；不代表Checkpoint已完成。
- 核心代码由学习者逐步实现。仿真依赖在独立工作空间维护，不包含课程notebook、原始图片或其他课程专有素材。

## 计划中的ROS 2包

1. `wheel_velocities_publisher`：按课程要求发布四轮速度。
2. `kinematic_model`：将四轮速度转换为`geometry_msgs/msg/Twist`，发布到`/cmd_vel`。
3. `eight_trajectory`：根据位姿反馈生成四轮命令，执行指定路线。

## 已核对的运行几何参数

课程云端控制器与本地仿真参数一致（2026-09-29）：

| 参数 | 数值 |
| --- | --- |
| 轮半径 | 0.05 m |
| 前后轮中心距离 | 0.17 m |
| 左右轮中心距离 | 0.27 m |

采用中心对称模型时，前后、左右半距分别为0.085 m、0.135 m。课程尺寸图的左右轮中心距离为269.69 mm；代码计划采用已核对的运行值270 mm，保留这一来源差异。
